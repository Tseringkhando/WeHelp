# WeHelp - Community Support & Volunteer Platform

**WeHelp** is an Android mobile application that connects volunteers with people who need assistance in their community. This project demonstrates expertise in Android development, Firebase integration, real-time location services, and user authentication.

## 🚀 Project Overview

WeHelp enables users to:
- Post requests for help in their community
- Discover nearby opportunities to volunteer
- Connect with others through a secure platform
- Receive notifications about assistance available
- Track volunteer activities using real-time maps

This is a full-featured Android application built for portfolio demonstration.

## ✨ Key Features

- **User Authentication** - Firebase-based secure login and registration
- **Real-time Location Services** - Google Maps integration for finding nearby help requests
- **Cloud Database** - Firebase Firestore for storing user profiles and requests
- **Image Management** - Upload and crop profile photos
- **Material Design UI** - Modern, responsive user interface
- **Permissions Management** - Smart permission handling with Dexter
- **AI Assistant** - IBM Watson integration for user support

## 🛠️ Tech Stack

- **Language**: Java
- **Platform**: Android (API 22-29)
- **Backend**: Firebase (Authentication, Firestore, Functions)
- **Maps & Location**: Google Maps, Google Play Services
- **AI/ML**: IBM Watson (Assistant, Text-to-Speech, Speech-to-Text)
- **Image Processing**: Android Image Cropper, Glide, Picasso
- **UI Framework**: Material Design, AndroidX
- **Build System**: Gradle
